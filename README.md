# STAR App

**5-Minute Speeches, Powered by Star Bobatoon's Methodology**

STAR App is a Next.js web application that generates compelling 5-minute speeches using Star Bobatoon's proprietary speechwriting methodology and produces audio output via Fish Audio text-to-speech.

## Overview

- **Method-Driven Writing** — Speeches are crafted using Star Bobatoon's structured approach to persuasive speaking
- **Audio Generation** — Written speeches are converted to natural-sounding audio via Fish Audio TTS
- **Next.js Frontend** — Modern React-based web interface for composing and delivering speeches

## Tech Stack

- Next.js
- TypeScript
- Fish Audio API (TTS)
- Deployed via PM2 + Cloudflare tunnel

## Getting Started

```bash
npm install
npm run dev
```
